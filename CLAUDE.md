# anky

An iOS app for tracking ankylosing spondylitis symptoms. It is open source under the MIT license. It handles health
data, so it stays on the device unless the stakeholder decides otherwise. Never commit real symptom data, not even as a
test fixture. Product calls about privacy are the stakeholder's, so ask before adding analytics, network sync, or
HealthKit.

## Toolchain

- Xcode 26.6 and Swift 6. SwiftFormat 0.64.3, SwiftLint 0.65.1, XcodeGen 2.46.0, lizard 1.24.3.
- The layers are Swift packages. `AnkyDomain` is pure logic and imports only Foundation. UI code lives in `App/` and
  compiles only through `xcodebuild`, since `swift test` builds every package target for macOS.
- `Anky.xcodeproj` is generated by `xcodegen generate` and is not committed. Add a file under `Sources/` or `App/` and
  touch no project file. `Package.swift` and `project.yml` are the only hand-kept build files.
- Dependencies are Swift Package Manager only, pinned with `exact:`.

## Before calling work done

Run these from the worktree root. CI runs the same ones.

- `swiftformat --lint .`
- `swiftlint lint --strict`
- `python3 -m lizard -l swift -ENS -Ecognitive -C 10 -L 40 -a 4 -T cognitive_complexity=12 -T max_nested_structures=3 -w -x "*/Tests/*" Sources App`
- `scripts/ci/check-layers.sh`
- `scripts/ci/check-privacy.sh`, and `scripts/ci/test-check-privacy.sh` when you change it
- `swift test --scratch-path .build`
- `xcodegen generate`, then `xcodebuild build -project Anky.xcodeproj -scheme Anky -destination 'generic/platform=iOS Simulator' -derivedDataPath .derived -clonedSourcePackagesDirPath .spm`
- `proquo --explain origin/main...HEAD` prices the diff. Split it when it prices red.

## Parallel workers

Every worktree keeps its own `.build`, `.derived`, `.spm` and `.results`. Never share DerivedData. A worker that needs a
simulator creates its own with `xcrun simctl create` and addresses it by UDID, never by name.
